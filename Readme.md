# 🤖 Resume Skill Chatbot

An AI-powered chatbot that answers questions about my resume, technical skills, education, projects, and experience using a custom `skill.md` knowledge base.

The chatbot is designed to provide recruiters, employers, and visitors with an interactive way to explore my professional background instead of reading a traditional resume.

## 🚀 Features

- Answers questions using a custom resume knowledge base
- Provides information about technical skills and projects
- Explains education and certifications
- Interactive conversational interface
- Built using Python and Large Language Models (LLMs)

## 🛠️ Tech Stack

- Python
- Markdown Knowledge Base (`skill.md`)
- LLM
- Prompt Engineering

## 📂 Project Structure

```
Resume-Chatbot/
│── skill.md
│── chatbot.py
│── README.md
```

## 🎯 Purpose

This project demonstrates how Large Language Models can be used to create a personalized AI assistant capable of answering questions about an individual's professional profile.
